# GAT
 GAT (Gif and text) - свой бинарный формат файла, который хранит текст и гифки в одном файле.

 # установка
```bash
git clone https://github.com/bulba2280/GAT
cd GAT
dotnet run
```

# как использовать
1) запустите (dotnet run)
2) напишите 1 | 2 (1 - создать gat файл, 2 - прочитать gat файл)
3) если выбрали "1", то введите текст и путь до гифки. Вы получите "output.gat".
4) если выбрали "2", то введите путь по .gat файла и получите информацию по нему.

# примеры
создание:
```bash
PS E:\GAT> dotnet run
1 - Создать GAT файл
2 - Прочитать GAT файл
Выбери: 1
НАпишите текст: ку, это текст для .gat файла
Напишите путь к гифке (Enter если нет): E:\GAT\cat.gif              
чекай ;3
```

чтение:
```bash
PS E:\GAT> dotnet run
1 - Создать GAT файл
2 - Прочитать GAT файл
Выбери: 2
Путь к файлу: E:\GAT\output.gat

[Блок 1] Текст:
ку, это текст для .gat файла
[Блок 2] Гифка сохранена: gif_2.gif (18674 байт)
PS E:\GAT> 
```
